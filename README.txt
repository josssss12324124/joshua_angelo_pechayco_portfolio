HOW TO RUN
----------
1. Extract the ZIP file.
2. Copy your existing images into assets/images/.
3. Rename the images to match the filenames listed below.
4. Put your resume PDF in the project root and name it resume.pdf.
5. Open index.html in your browser, or use VS Code Live Server.
6. Test every link and image before uploading the site.
