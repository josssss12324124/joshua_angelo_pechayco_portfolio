Overview

An IoT-based emergency response system designed to help elderly individuals and Persons with Disabilities (PWDs) request immediate assistance through a GPS-enabled wearable device or web-based SOS button. It connects users with Emergency Medical Services (EMS) and barangay responders through real-time alerts and location tracking.

Problem and solution

Traditional emergency reporting can be difficult for elderly and PWDs, especially when they cannot make phone calls or communicate their exact location. The system addresses this through one-press SOS alerts that automatically transmit user information and GPS coordinates to emergency responders.

Key Features

  • One-Press SOS Alert: Send emergency requests through the wearable device or web application.
  • Real-Time GPS Tracking: Display the user's location on an interactive map.
  • Emergency Dashboard: Monitor active alerts and response status.
  • Alert Management: Acknowledge, update, and resolve emergency cases.
  • Automatic Alert Rerouting: Forward unacknowledged alerts to the next available verified responder.
  • User Management: Manage registered users and responder accounts.
  • Alert History and Reports: Review previous incidents and generate reports.
  • Role-Based Access: Provide separate access for EMS administrators, barangay responders, and end users.

System workflow

  • The ESP32-based device detects a user-triggered distress event.
  • The device obtains location information through a GPS module.
  • Alert details and coordinates are written to Firebase Realtime Database.
  • The monitoring interface retrieves alert records and displays them for authorized users.
  • Responders can review alert status and location information.
