Overview

GECKER (General Education Curriculum Examination Checker) is an AI-powered web application designed to help instructors automate the checking of major examinations. It processes student answer sheets, detects marked answers, and automatically calculates scores to make examination checking faster and more efficient.

Problem and solution

Manual examination checking is time-consuming and repetitive. GECKER addresses this by automating answer detection and score calculation, reducing instructors' workload and improving checking efficiency.

Processing workflow

  • Prepare Answer Key: Create or upload an examination answer key.
  • Upload Answer Sheet: Submit a student's answer sheet for processing.
  • Detect Answers: Analyze shaded responses using image processing and machine learning
  • Compare detected responses with the answer key.
  • Generate Results: Automatically calculate and display examination scores.
